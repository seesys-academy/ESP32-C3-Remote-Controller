# Test_07_WebDashboard - שלט מחובר לדף אינטרנט (לוח יחיד)

תרגיל 7 ברצף התרגילים - **לוח אחד** משדר רשת WiFi, מריץ שרת אינטרנט + שרת
WebSocket, ומגיש דשבורד גרפי שמראה בזמן אמת את כל מצב השלט (ג'ויסטיק,
כפתורים, הטיה, מנוע, לדים). בלי צורך במכשיר שני.

מבוסס על הפרויקט האמיתי `ESP32C3042` (המקור המקורי מגובה כארכיון ב-
`D:\2026\BOOK_9\CODE\V2\ESP32C3 0.42 Contoller\ZIP\ESP32C3042.rar`).

פותחים דפדפן על `http://192.168.4.1/` (אחרי שמתחברים לרשת שהלוח משדר)
ורואים את כל מצב השלט בזמן אמת.

**כשיהיה לוח ESP32 שני** - יש גם גרסת שני-מכשירים מוכנה ב-
[ESP32_Console](../../../ESP32_Console) (שלט כ-WebSocket Client + קונסולה נפרדת
כ-AP/שרת), שמורה בצד לשלב הבא. **כרגע `Test_07_WebDashboard` הוא מה
שמעלים - זה מכיל את הכל בלוח אחד.**

## מה נוסף כאן לעומת הארכיון המקורי (2026-07-17)

הקוד המקורי כלל הגדרת `MOTOR_PIN` בהערה (`//#define MOTOR_PIN 8`) בלי שום
לוגיקה בפועל, ושום קוד לדים. **תוקן גם באג פינים**: הקוד המקורי הגדיר
`RIGHT_PIN=10` וניחש `MOTOR_PIN=8` בהערה - הפוך מהסכמה המקורית של הלוח
(`SW_RIGHT=IO8`, `MOTOR_PIN=IO10`). אושר מול החומרה בפועל שהמנוע אכן על
הדק 10 - הפינים הוחלפו בהתאם. הוספתי:

1. **מנוע רטט פעיל** (`MOTOR_PIN = 10`) - נדלק כשההטיה חוצה סף
   (`MOTOR_TILT_THRESHOLD`), או כשמזוהה "attack" (טלטול על ציר Z).
2. **4 לדים RGB (WS2812B)** (`LEDS_PIN = 1`) - נדלקים אדום כשההטיה שמאלה
   מעבר לסף (`LED_TILT_THRESHOLD`), כחול כשההטיה ימינה, כבויים במרכז.
3. **הרחבת ה-JSON שנשלח לקונסולה** - נוספו השדות `"motor"` ו-`"led"`
   שמשקפים בדיוק את המצב האמיתי של המנוע/הלדים על השלט, כדי שהדשבורד
   ב-[ESP32_Console](../../../ESP32_Console) יציג חיווי מדויק ולא קירוב.

```
CTRL:{"left":0,"right":1,"up":0,"down":0,"select":0,"tilt":12000,"attack":0,"motor":1,"led":2}
```

## תיקון פינים (2026-07-17)

RIGHT_PIN ו-MOTOR_PIN הוחלפו כדי להתאים לסכמה המקורית ולחיווט האמיתי
(המנוע מחובר בפועל להדק 10):

| | לפני (שגוי) | אחרי (מתוקן) |
|---|---|---|
| RIGHT_PIN (KEY2) | 10 | **8** |
| MOTOR_PIN | 8 | **10** |

## חיווי חי על מסך ה-OLED (בלי Serial Monitor)

`drawStatus()` ב-`functionsOfOled.ino` רץ בכל סיבוב לולאה ומציג על המסך:
```
T:<tilt>
L:<left> R:<right> A:<attack>
M:<ON/OFF> LED:<RED/BLU/->
```
כך אפשר לבדוק/לכוונן את השלט לבד, בלי חיבור למחשב.

## מנוע ולדים - מגיבים לג'ויסטיק, לא להטיה

בהתחלה המנוע/הלדים הגיבו לערך ה-"tilt" מה-MPU6050 - אבל רטט המנוע עצמו
מנער את החיישן ויוצר משוב עצמי (המנוע "חושב" שיש עוד הטיה כי הוא בעצמו
מרעיד את הלוח). לכן הם עברו להגיב **לאירועי ג'ויסטיק בלבד** (רגע הלחיצה
לקצה, לא כל עוד מוחזק), בפולס קצר:
- `MOTOR_PULSE_MS` (120) - מנוע רוטט לזמן קצר בכל לחיצה לכיוון כלשהו **בג'ויסטיק בלבד** (לא attack/טלטול לוח - זה עדיין תנועת MPU, לא ג'ויסטיק).
- `LED_PULSE_MS` (350) - **כל 4 הלדים** נדלקים יחד (`strip.fill()`) לזמן קצר:
  אדום=שמאלה, כחול=ימינה, ירוק=למעלה, צהוב=למטה.

ה-"tilt" עדיין נשלח ומוצג במד ההטיה בדשבורד - רק לא מפעיל יותר מנוע/לדים.

## מבנה קבצים

- `Test_07_WebDashboard.ino` - ראשי: setup/loop, כפתורים, ג'ויסטיק, שידור JSON.
- `functionsOfOled.ino` - מסך OLED, כולל `drawStatus()` לחיווי חי.
- `functionsOfMpu6050.ino` - **כל** מה שקשור לחיישן ה-MPU6050 (אתחול, קריאת הטיה מוחלקת, זיהוי "מכה", התאוששות מקריסת I2C).
- `functionsWiFi.ino` - AP.
- `functionsWebServer.ino` - שרת HTTP (מגיש את data/).
- `functionsWebSockets.ino` - שרת WebSocket.

## פינים (מתוקנים, תואמים לסכמה המקורית)

| פונקציה | GPIO |
|---|---|
| SDA / SCL (מסך + MPU6050) | 5 / 6 |
| ג'ויסטיק VRY / VRX | 3 / 4 |
| ג'ויסטיק SW (select) | 7 |
| כפתור שמאל (LEFT) | 0 |
| כפתור ימין (RIGHT) | 8 |
| מנוע רטט (MOTOR) | 10 |
| לדים WS2812B (LEDS) | 1 |

## ספריות נדרשות

- **WebSockets** by Markus Sattler (Links2004) - כבר הייתה בשימוש (כ-Client), עכשיו בשימוש כ-Server (`WebSocketsServer.h`).
- **Adafruit NeoPixel** - עבור 4 הלדים (נוסף כאן, לא היה בארכיון המקורי).
- `WiFi.h`, `WebServer.h`, `LittleFS.h` - מובנות בליבת ESP32, אין צורך להתקין.

## חשוב - צריך להעלות גם את תיקיית data בנפרד

תיקיית `data/` (הדף הגרפי) **לא** מתקמפלת עם הקוד - צריך כלי נפרד
("ESP32 LittleFS Data Upload" plugin ל-Arduino IDE) כדי לצרוב אותה לפלאש.
בלי זה, השרת ירוץ אבל הדף לא יופיע (LittleFS.begin ייכשל). סדר העלאה:
1. מעלים קודם את תיקיית `data/` דרך התוסף.
2. **אחר כך** מעלים את הקוד הרגיל (`Test_07_WebDashboard.ino`).

## איך מתחברים

1. מעלים את `Test_07_WebDashboard.ino` (אחרי שהעלו את `data/`).
2. מתחברים ממחשב/טלפון לרשת `ESP32_Console_V2` (סיסמה `87654321`) - זו
   הרשת שהלוח עצמו משדר עכשיו.
3. פותחים דפדפן בכתובת `http://192.168.4.1/`.

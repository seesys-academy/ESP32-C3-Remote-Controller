3 — נקודות קריטיות בקוד

ג'ויסטיק — חובה ADC_11db

ברירת מחדל = 0–1.1V. ג'ויסטיק = 0–3.3V:

analogSetPinAttenuation(3, ADC_11db);
analogSetPinAttenuation(4, ADC_11db);

סף: <500 ו->3500 (12-bit, מרכז ~2048)

כפתורים — INPUT_PULLUP

כל כפתורי הלחיצה active LOW:

pinMode(0,  INPUT_PULLUP); // SW_LEFT
pinMode(9,  INPUT_PULLUP); // SW_RIGHT
pinMode(7,  INPUT_PULLUP); // SW_JOY

מד סוללה — R12/R13

מחלק מתח R12=30kΩ, R13=110kΩ:

Vbat = (raw/4095.0) * 3.3
     * (30.0+110.0) / 110.0;

4.2V מלאה → 3.3V על ADC

MPU6050 — Wire reset

כתובת: 0x68 (AD0→GND)

Wire.end();  delay(10);
Wire.begin(5, 6);   // SDA, SCL
Wire.setClock(400000);

6 — פתרון בעיות נפוצות

⚠
MPU6050 לא נמצא — הרץ Test_00_I2C_Scanner. אם מצא רק 0x3C: בדוק חיווט, ודא AD0→GND, הרץ שוב.
⚠
ג'ויסטיק לא מגיב / ערכים קטנים — ודא שהוספת analogSetPinAttenuation(..., ADC_11db). בלי זה הטווח מוגבל ל-0–1.1V.
⚠
Serial Monitor לא עובד — ESP32-C3 לעיתים צריך לחיצה על BOOT בזמן חיבור. לחלופין — כל המידע מוצג על ה-OLED.
⚠
מסך OLED קפוא — ה-OLED לא מוחק את עצמו אם I2C נתקע. ודא שהתוכן משתנה בזמן אמת; נתק חשמל בין בדיקות.
✓
